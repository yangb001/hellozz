# 多会话 Agent 框架详细实现设计

## 1. 架构总览与模块职责

| 模块               | 职责                                         | 对外接口                          |
| ------------------ | -------------------------------------------- | --------------------------------- |
| **interfaces**     | 定义所有抽象基类和数据结构，实现模块间零耦合 | 无外部依赖                        |
| **core**           | 会话管理器、事件总线、全局配置               | `SessionManager`, `EventBus`      |
| **runtime**        | Agent 运行时引擎（无状态）                   | `AgentRuntime`                    |
| **memory**         | 记忆系统（短期/长期/用户级）                 | `MemoryManager` 实现 `BaseMemory` |
| **planners**       | 各种规划策略                                 | 实现 `BasePlanner`                |
| **tools**          | 工具注册与执行                               | `ToolRegistry`, 各类 `BaseTool`   |
| **gateway**        | 接入层（REST + WebSocket）                   | FastAPI 应用                      |
| **infrastructure** | LLM网关、存储适配器（Redis/向量库）          | `LLMGateway`, `Storage`           |
| **adapters**       | 未来拆分时的 gRPC/HTTP 客户端（可选）        | 初期可不实现                      |

所有实现模块**仅依赖 `interfaces`**，通过依赖注入组装。

## 4. 会话管理器详细设计 (core/session_manager.py)

```python
class SessionManager:
    def __init__(
        self,
        memory_factory: Callable[[str], BaseMemory],
        runtime: 'AgentRuntime',
        planner: BasePlanner,
        tools: Dict[str, BaseTool],
        event_bus: EventBus,
        storage: SessionStorage,      # 持久化接口
        llm_gateway: LLMGateway
    ):
        self.memory_factory = memory_factory
        self.runtime = runtime
        self.planner = planner
        self.tools = tools
        self.event_bus = event_bus
        self.storage = storage
        self.llm_gateway = llm_gateway
        self._active_sessions: Dict[str, SessionContext] = {}
        self._session_queues: Dict[str, asyncio.Queue] = {}  # Actor 队列

    async def create_session(self, user_id: str, session_type="private",
                             participants=None) -> SessionContext:
        sid = generate_id()
        ctx = SessionContext(
            session_id=sid, session_type=session_type,
            participants=[user_id] + (participants or [])
        )
        self._active_sessions[sid] = ctx
        self._session_queues[sid] = asyncio.Queue()
        asyncio.create_task(self._session_actor(sid))   # 启动Actor
        await self.storage.save(ctx)
        return ctx

    async def _session_actor(self, sid: str):
        """每个会话的串行处理循环"""
        q = self._session_queues[sid]
        while True:
            user_msg, future = await q.get()
            try:
                ctx = self._active_sessions[sid]
                memory = self.memory_factory(sid)
                # 调用运行时获取事件流
                events = self.runtime.run(
                    ctx=ctx, user_input=user_msg,
                    memory=memory, tools=self.tools,
                    planner=self.planner, llm_gateway=self.llm_gateway
                )
                collected = []
                async for event in events:
                    collected.append(event)
                    await self.event_bus.publish(sid, event)   # 转发给接入层
                future.set_result(collected)
                await self.storage.save(ctx)
                # 触发记忆提取（异步）
                asyncio.create_task(memory.extract_long_term(sid))
            except Exception as e:
                future.set_exception(e)

    async def process_message(self, session_id: str, user_msg: dict) -> asyncio.Future:
        """接入层调用此方法投递消息，返回Future以异步等待结果"""
        future = asyncio.Future()
        await self._session_queues[session_id].put((user_msg, future))
        return future

    # 其他方法: get_session, close_session, resume_session 等...
```

## 5. Agent 运行时详细设计 (runtime/agent_runtime.py)

```python
class AgentRuntime:
    async def run(
        self,
        ctx: SessionContext,
        user_input: str,
        memory: BaseMemory,
        tools: Dict[str, BaseTool],
        planner: BasePlanner,
        llm_gateway: LLMGateway
    ) -> AsyncIterator[Event]:
        # 添加用户消息到上下文
        msg = Message(role="user", content=user_input, sender_id="...")
        ctx.messages.append(msg)
        await memory.save(ctx.session_id, msg)

        # 定义 llm_call 闭包，供规划器调用
        async def llm_call(prompt: str, **kwargs) -> AsyncIterator[str]:
            # 调用 LLM 网关，可流式返回
            async for token in llm_gateway.stream(prompt, **kwargs):
                yield token

        # 启动规划器
        final_answer = None
        async for event in planner.plan_and_act(ctx, memory, tools, llm_call):
            # 如果事件为最终回复，保存到上下文
            if event.type == "final_answer":
                final_msg = Message(role="assistant", content=event.content)
                ctx.messages.append(final_msg)
                await memory.save(ctx.session_id, final_msg)
            yield event

        # 更新会话活跃时间
        ctx.last_active = datetime.utcnow()
```

## 6. 记忆系统详细设计 (memory/)

### 6.1 MemoryManager（统一入口，实现 BaseMemory）

```python
class MemoryManager(BaseMemory):
    def __init__(self, short_term: BufferMemory, long_term: VectorMemory,
                 extractor: MemoryExtractor, config: MemoryConfig):
        self.short_term = short_term
        self.long_term = long_term
        self.extractor = extractor
        self.config = config  # 包含触发策略等

    async def save(self, session_id: str, message: Message):
        await self.short_term.add(session_id, message)
        # 如果启用智能识别，异步检查是否需要立即提取
        if self.config.trigger == "smart":
            asyncio.create_task(self._smart_extract(session_id, message))

    async def retrieve(self, session_id, query, user_ids=None, top_k=5):
        # 短期记忆（直接拿最近N条）
        short_ctx = await self.short_term.get_recent(session_id, n=10)
        # 长期记忆（向量检索）
        long_ctx = await self.long_term.query(session_id, query, top_k=top_k)
        # 用户记忆（跨会话）
        user_ctx = ""
        if user_ids:
            for uid in user_ids:
                mem = await self.long_term.query_user(uid, query, top_k=2)
                user_ctx += mem
        # 简单拼接，也可按相关性排序
        return f"{user_ctx}\n{long_ctx}\nRecent: {short_ctx}"

    async def extract_long_term(self, session_id: str, force=False):
        recent = await self.short_term.get_recent(session_id, n=20)
        facts = await self.extractor.extract(recent)  # 调用LLM提取
        for fact in facts:
            await self.long_term.add(session_id, fact.content, fact.metadata)
            if fact.user_id:   # 同时写入用户记忆
                await self.long_term.add_user(fact.user_id, fact.content)

    async def _smart_extract(self, session_id, message):
        # 轻量判断是否需要即时提取
        if await self.extractor.is_important(message):
            await self.extract_long_term(session_id, force=True)
```

### 6.2 BufferMemory（短期）

```python
class BufferMemory:
    def __init__(self, max_tokens=2000):
        self.buffers = defaultdict(list)  # {session_id: [Message]}

    async def add(self, session_id, msg):
        self.buffers[session_id].append(msg)
        # 按token数截断

    async def get_recent(self, session_id, n=10):
        return "\n".join([m.content for m in self.buffers[session_id][-n:]])
```

### 6.3 VectorMemory（长期）

```python
class VectorMemory:
    def __init__(self, vector_store: VectorStoreClient):
        self.store = vector_store

    async def add(self, session_id, text, metadata=None):
        await self.store.add(collection=session_id, text=text, metadata=metadata)

    async def query(self, session_id, query, top_k=5):
        results = await self.store.query(collection=session_id, query=query, top_k=top_k)
        return "\n".join([r.text for r in results])

    async def add_user(self, user_id, text):
        await self.store.add(collection=f"user:{user_id}", text=text)

    async def query_user(self, user_id, query, top_k=5):
        results = await self.store.query(collection=f"user:{user_id}", query=query, top_k=top_k)
        return "\n".join([r.text for r in results])
```

```python
class MemoryExtractor:
    def __init__(self, llm_gateway: LLMGateway, model_name="light-model"):
        self.llm = llm_gateway
        self.model = model_name

    async def extract(self, messages: List[Message]) -> List[MemoryFact]:
        prompt = f"Extract factual statements from:\n{messages}\nReturn JSON list."
        raw = await self.llm.generate(prompt, model=self.model)
        return parse_facts(raw)

    async def is_important(self, msg: Message) -> bool:
        # 快速分类
        prompt = f"Is this message important for long-term memory? {msg.content}"
        ans = await self.llm.generate(prompt, model=self.model, max_tokens=2)
        return "YES" in ans
```

## 7. 规划器详细设计 (planners/)

以 ReAct 为例：

```python
class ReActPlanner(BasePlanner):
    async def plan_and_act(self, ctx, memory, tools, llm_call):
        # 构建系统提示
        prompt = self._build_prompt(ctx, memory, tools)
        while True:
            # 调用 LLM，流式输出
            full_text = ""
            async for token in llm_call(prompt):
                full_text += token
                yield Event(type="text_token", content=token)
            # 解析行动
            action = self._parse_action(full_text)
            if action.type == "final_answer":
                yield Event(type="final_answer", content=action.content)
                break
            elif action.type == "tool_call":
                yield Event(type="action", content=f"Calling {action.tool}...")
                tool = tools[action.tool]
                result = await tool.run(action.input, session_id=ctx.session_id)
                prompt += f"\nObservation: {result}"
                yield Event(type="observation", content=result)
            # 循环继续
```

## 11. 群组会话与交叉记忆实现要点

- 创建群组：`SessionContext(session_type="group", participants=[...])`
- 消息需带 `sender_id`，规划器和记忆系统均可使用。
- MemoryManager 的 `retrieve` 若收到 `user_ids` 参数，则调用 `VectorMemory.query_user` 获取跨会话记忆。
- 用户记忆写入：提取器提取的事実如果包含 `user_id` 且标记为个人事实，则同时写入 `user:{user_id}` 集合。
- 隐私控制：`retrieve` 前可检查请求的 `user_ids` 是否在当前会话的 `participants` 中。

## 12. 单体到微服务的平滑演进

当前所有调用均为进程内函数调用。如需拆分微服务，只需：
1. 为需要拆分的模块定义 gRPC 服务（如 `MemoryService`）。
2. 实现一个 `MemoryGrpcClient` 继承 `BaseMemory`，内部通过 gRPC 调用远程服务。
3. 在组装依赖时，将 `memory_factory` 改为返回 `MemoryGrpcClient` 实例。
核心业务代码无需任何修改。
